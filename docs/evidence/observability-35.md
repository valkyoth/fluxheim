# Native TLS-ALPN-01 qualification

The CA, gateway, and renewal companion are separate processes. No public CA
or public DNS is involved. Pebble validates the actual TLS handshake, the SAN,
the negotiated protocol and the critical ACME identifier. A second issuer
account prevents a cached authorization from substituting for a fresh test.
For ordinary HTTPS the test pins and compares the exact installed leaf.

- `sh scripts/check_acme_scope.sh`: packaged Wolfi gateway and companion,
  TLS-ALPN-01 first issuance and renewal, and the existing HTTP-01 suite.
- `scripts/smoke_native_acme_alpn.py`: native Linux, macOS and Windows.
  Both background and external modes obtain and replace the certificate.
  External activation is tested with a gateway restart; this does not
  claim Windows supports Unix certificate-reload commands.
- The native cancellation scenario holds a real challenge response at the
  CA adapter while checking ordinary HTTPS, missing/wrong SNI and mixed
  protocols. Terminating only the companion must remove the temporary
  identity without stopping the gateway. Restart must not republish it.
- On Unix, an offline doctor on an empty external installation must create
  service-owned `0700` storage without binding a socket. In every mode
  of `scripts/smoke_acme_mount_boundary.sh`, a separate two-UID test
  verifies a root broker refuses foreign storage, an untrusted ancestor and
  a foreign publication directory without changing their contents or owners.

To repeat the native proof, build `fluxheim` and `fluxheim-acme` with
`--locked --no-default-features --features profile-web-server,acme-client`.
Supply a local Pebble v2.10.1 binary and the three **disposable fixture**
files `ca.pem`, `server.pem`, `server.key` generated by
`scripts/smoke_acme_scope.py`'s `fixtures` helper (never use production
credentials). Use Python 3.13+ with OpenSSL partial-chain support:

```sh
python3 scripts/smoke_native_acme_alpn.py --bin-dir target/debug \
  --pebble /path/to/pebble --fixture /path/to/disposable/control
```

The smoke requires free loopback ports 5002, 5443, 14000, 14001 and 15000,
IPv4 and IPv6 localhost, and a user-private temp directory. It is not a
test of public DNS, ingress routing, an external CA's policies, or failover
between gateway instances.
